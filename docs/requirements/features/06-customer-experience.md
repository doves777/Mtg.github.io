## Overview

Buyers should be able to discover a vendor's inventory, reserve or purchase for pickup, and stay informed about order status — with as little friction as possible.

## Requirements

- [ ] **CX-1** — Customers can browse available inventory.
- [ ] **CX-2** — Customers can search by card, set, player, team, game, condition, price, or category.
- [ ] **CX-3** — Customers can place pickup orders.
- [ ] **CX-4** — Customers receive confirmation and pickup instructions.
- [ ] **CX-5** — Customers can see order status.
- [ ] **CX-6** — Customers can create an account or check out as guest.
- [ ] **CX-7** — Customers can save favorite items or want lists.
