## Vendor Owner

- As a vendor owner, I want to upload my inventory so my team can quickly search and sell cards at shows.
- As a vendor owner, I want to assign inventory to a specific show so I know what is available at that event.
- As a vendor owner, I want to view event sales reports so I can understand which cards sold well.
- As a vendor owner, I want to control employee permissions so only approved people can discount or override prices.
- As a vendor owner, I want to cache prices offline so my team can continue selling when Wi-Fi is poor.
- As a vendor owner, I want to publish scalable buylist prices so my team can confidently buy cards at shows.
- As a vendor owner, I want accepted buy orders to become inventory so acquisition and resale workflows stay connected.

## Employee

- As an employee, I want to quickly search for a card so I can help customers faster.
- As an employee, I want to build an order without manually adding totals so I can avoid mistakes.
- As an employee, I want to see current pricing so I can quote customers accurately.
- As an employee, I want to mark pickup orders as complete so inventory stays accurate.
- As an employee, I want to quickly quote buy prices so I can evaluate customer trade-ins without slowing down the booth.
- As an employee, I want to submit high-value buy offers for approval so the owner can control risk.

## Customer

- As a customer, I want to browse a vendor's available cards before a show so I can plan purchases.
- As a customer, I want to reserve cards for pickup so I don't miss out on inventory.
- As a customer, I want to see pickup instructions so I know where and when to collect my order.
- As a customer, I want to submit cards I want to sell so I can get a cash or trade-in offer from the vendor.
- As a customer, I want to see whether my sell list was accepted, rejected, or countered so I know what to bring or ship.
